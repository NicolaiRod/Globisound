# Globisound – Live World Radio & Video Streams

**Globisound** is a lightweight, feature-rich desktop application for Windows that lets you explore and stream thousands of live radio stations and video streams from around the globe.

## 🌟 Key Features

- **🌍 Global Station Browser:** Easily search and filter radio stations by country, name, or music genre.
- **🎵 Auto Shazam Song Identification:** Automatically detects and displays the currently playing track and artist in real time.
- **📜 Live Lyrics Search:** Fetch song lyrics on the fly with a single click.
- **🎨 Audio Spectrum Visualizer:** Real-time audio spectrum visualization with interactive particle physics.
- **📺 Video Radio & Stream Support:** Embedded video panel supporting video streams, `.m3u8`, and live feeds.
- **🌐 Multi-Language Interface:** Available in Danish, English, German, Spanish, and French.
- **🎨 Customizable Themes:** Choose between multiple color themes (Dark Mode, Cyberpunk, Ocean Blue, etc.).

## 🚀 Installation & Download

> **Note for Windows Users:** Because this app is independently developed without a paid commercial certificate, Windows Defender SmartScreen might show a warning. Click **"More info"** and then **"Run anyway"** to proceed.

1. Download the latest `Globisound_Setup.exe` from [GitHub Releases](https://github.com/NicolaiRod/Globisound/releases), or https://villaen.dk/Globisound_Setup.exe
2. Run the installer and follow the on-screen instructions.
